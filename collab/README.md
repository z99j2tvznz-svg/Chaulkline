# Chalkline collaboration data

Shared data for outside review (e.g. ChatGPT). This folder is data only: nothing here is used by the app, and the app,
tracker v0.6 and the reader are unchanged. Add new shared material as a new dated folder next to the existing ones.

| Folder | What it is |
|---|---|
| [recognition-package-2026-10-20](recognition-package-2026-10-20/README.md) | Ball-recognition evaluation package: exact reader pictures, player-verified labels, frozen reader + detector, frozen detections, experiment results, v0.6 scoring. Start with its README. |

Not here yet (too large for the repository): the raw video footage (~700 MB in three ZIPs). Ask for it if a method
needs to cut new pictures from video.

This repository is public.
