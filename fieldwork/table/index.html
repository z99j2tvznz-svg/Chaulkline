MODULE CONTRACT

VERSION 1
Inputs: camera/image pixels, four manually observed corners, selected table size, calibration revision.

Outputs: normalized corners, physical dimensions (inches), 3×3 image-to-table projection, and provider ID.

What this proves: real image rectification and a replaceable software boundary.

What it does not prove: automatic table recognition, ball identity, stroke detection, optical accuracy or physics.
Next component is NOT automatically connected. Ball detection requires a separate approval and measured trials on actual pool footage.
