# Fieldwork Safari preview

This folder publishes the separate **ChatGPT / Fieldwork** experimental foundation interface through the existing GitHub Pages site. It does not replace the production Chalkline entry page.

**Route:** /Chaulkline/fieldwork/

The page consumes nine synthetic, hand-authored scenarios. It is a state/event interpreter **demo**, not a camera-based pool tracker or a gameplay app. No real-footage accuracy has been measured.

Source of the copied UI and unchanged engine/scenarios:
`chatgpt/foundation-fieldwork/` on the development branch.
The source engine and scenario scripts are copied unchanged; the HTML asset paths were adjusted to work at this standalone published path.

Do not promote these results to release readiness. Review and real-recording benchmarks are required before integration.
